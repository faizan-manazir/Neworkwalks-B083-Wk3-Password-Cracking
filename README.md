# Networkwalks B083 — Week 3 Password Cracking

## Project Overview

This repository documents the completion of the **Week 3 Password Cracking Project** for the Networkwalks B083 cybersecurity training module. The work was performed in a controlled educational lab environment using the tools and challenge files provided for the project.

The repository contains the implementation workflow and supporting evidence for both required practical modules.

## Required Modules

| Module | Topic | Status |
|---|---|---|
| **W3-PM1** | Password Cracking with John the Ripper (JTR) | ✅ Completed |
| **W3-PM2** | Password Cracking with Networkwalks Tools | ✅ Completed |

## W3-PM1 — John the Ripper

The first practical module demonstrates PDF password recovery using **John the Ripper (Jumbo)** and **Johnny GUI**. The workflow covers JTR verification, Johnny configuration, PDF hash extraction, hash loading, password-cracking execution, and final PDF verification.

📁 Evidence: `W3-PM1-JTR/screenshots/`

## W3-PM2 — Networkwalks Tools

The second practical module demonstrates PDF password recovery using the **Networkwalks Hash Calculator** and **Networkwalks Password Cracker**. The evidence includes the PDF2 hash extraction, successful password-cracking result/flag capture, and verification that the protected PDF can be opened.

📁 Evidence: `W3-PM2-Networkwalks/screenshots/`

## Learning Outcomes

This project provided practical experience with:

- Password-hash extraction from protected PDF files
- John the Ripper and Johnny GUI workflow
- Hash-based password recovery
- Networkwalks password-cracking utilities
- Verification of recovered credentials against protected files
- Maintaining structured technical evidence for a cybersecurity practical

## Ethical Use

All activities documented in this repository were performed for an **authorized educational cybersecurity exercise** using the supplied lab materials. The techniques demonstrated here should only be used against systems and files for which explicit authorization has been provided.
