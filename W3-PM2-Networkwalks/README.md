# W3-PM2 — Networkwalks Password Cracking

## Objective
Recover the password of the protected PDF using the Networkwalks Hash Calculator and Password Cracker in the controlled Week 3 lab environment.

## Workflow
1. Use the Networkwalks Hash Calculator to extract the PDF hash.
2. Copy the complete hash into the Networkwalks Password Cracker.
3. Start the password-cracking process.
4. Capture the successful flag/result.
5. Verify the recovered password by opening the corresponding protected PDF.
