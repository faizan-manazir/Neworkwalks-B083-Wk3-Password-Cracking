# W3-PM2 — Password Cracking with Networkwalks Tools

## Objective

Demonstrate PDF password recovery using the **Networkwalks Hash Calculator** and **Networkwalks Password Cracker** in the authorized Week 3 laboratory environment.

## Tools Used

- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Protected PDF supplied with the lab

## Practical Workflow

1. **Hash extraction** — Upload the protected PDF to the Networkwalks Hash Calculator and obtain the complete PDF password hash.
2. **Hash preparation** — Copy the extracted hash into the Networkwalks Password Cracker.
3. **Password recovery** — Start the cracking process and allow the tool to identify the matching password.
4. **Flag/result capture** — Record the successful cracking result/flag as project evidence.
5. **Verification** — Use the recovered password to open the protected PDF and confirm successful recovery.

## Result

The Networkwalks password-cracking workflow was completed successfully. The recovered credential was verified against the protected PDF, and the successful result was captured as project evidence.

> **Security note:** The recovered password, standalone hash, and original locked PDF are intentionally not stored in this public repository.

## Ethical Use

This procedure was performed only against the supplied project material in an authorized educational environment. Password-cracking techniques must not be applied to systems or files without explicit permission.
