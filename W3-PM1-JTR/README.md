# W3-PM1 — Password Cracking with JTR

## Objective
Recover the password of the supplied protected PDF using John the Ripper (JTR) and Johnny GUI in the controlled Week 3 lab environment.

## Workflow
1. Verify the John the Ripper Jumbo installation.
2. Configure Johnny GUI to use `john.exe` from the JTR `run` directory.
3. Extract the PDF password hash using the project-specified method.
4. Save the extracted hash as `hash1.txt`.
5. Load the hash in Johnny.
6. Start the password-cracking attack.
7. Verify the recovered password by opening the protected PDF.
